# AI Fitness Android App

## 💪 Overview
A personalized workout tracking Android application that helps users stay consistent with structured daily workout plans.

## 🚀 Features
- Daily workout plan (auto shown on app open)
- Muscle group based training (Chest, Triceps, etc.)
- Workout streak tracking 🔥
- Weight logging + progress graphs 📊
- Workout duration tracking ⏱

## 🛠 Tech Stack
- Java
- Android SDK
- XML UI
- Firebase
